# mel-simulator

## The Story of Mel - A Gorgeous Graphical Web Simulation

An immersive, interactive web experience that brings to life the legendary tale of Mel Kaye, a Real Programmer who wrote machine code in raw hexadecimal on drum memory computers in the 1960s.

### 🎨 Features

- **Stunning Retro Aesthetics**: Neon cyan, orange, and yellow colors with glowing effects that break away from the purple paradigm
- **Matrix-Style Hex Rain**: Animated hexadecimal characters falling like digital rain
- **Interactive Navigation**: Smooth section-switching navigation between story chapters
- **Animated Drum Memory**: Canvas-based visualization of the rotating drum with optimized instruction placement
- **Playable Blackjack Game**: Experience Mel's famous blackjack program with the infamous "sense switch" bug
- **Memory Overflow Visualization**: Clear explanation of Mel's genius loop-without-a-test trick
- **Responsive Design**: Works beautifully on desktop, tablet, and mobile devices

### 🚀 Getting Started

Simply open `index.html` in a modern web browser, or serve it with any web server:

```bash
python3 -m http.server 8000
# Then visit http://localhost:8000
```

### 📖 The Story

Based on the classic text "The Story of Mel - A Real Programmer" by Ed Nather, this simulation celebrates:

- **Hand-optimized machine code** written directly in hexadecimal
- **Drum memory optimization** where instruction placement was critical for performance
- **Self-modifying code** that used instructions as both code and data
- **The infamous overflow trick** that made a loop work without any test condition
- **Mel's ethical stand** that resulted in a backwards sense switch

### 🎮 Interactive Elements

1. **The Blackjack Game**: Play the same game that Mel wrote for the LGP-30. Try toggling the sense switch to see Mel's "bug" in action!

2. **Drum Animation**: Click "Animate Drum Optimization" to see how instructions are placed on the rotating drum for optimal performance

3. **Story Navigation**: Use the navigation bar to jump between different chapters of Mel's story

### 🎨 Color Palette

The design deliberately breaks away from the "purple paradigm" with a vibrant retro color scheme:

- Primary (Cyan): `#00ff9f`
- Secondary (Orange): `#ff6b35`  
- Accent (Yellow): `#ffd23f`
- Danger (Pink): `#ff006e`
- Background: Dark blues and blacks for that authentic terminal feel

### 💻 Technologies

- Pure HTML5, CSS3, and vanilla JavaScript
- Canvas API for drum visualization
- CSS animations and transitions for smooth effects
- Responsive design with CSS Grid and Flexbox
