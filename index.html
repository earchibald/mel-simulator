Meet Mel

LGP-30

I first met Mel when I went to work for Royal McBee Computer Corp.

Mel had written, in hexadecimal, the most popular program the company owned.

It ran on the LGP-30 and played blackjack with potential customers at computer shows.

"If a program can't rewrite its own code, what good is it?"
— Mel

The Art of Optimization

The RPC-4000 had a one-plus-one addressing scheme.

Every instruction included where the next instruction was located on the drum.

In modern parlance, every single instruction was followed by a GO TO!

Mel could optimize by locating instructions so they'd arrive at the read head exactly when needed.

Mel's Hand-Optimized Code:
3F A2 7C 15 8B D4 29 6E
Each instruction is also a constant that can be used in calculations!

The Blackjack Program

The sales department wanted Mel to let customers win by setting a sense switch.

Mel wrote the code, but got the test backwards...

When the sense switch is ON, the program cheats — winning every time.

The Mystery Loop

I found an innocent loop that had no test in it.

Common sense said it had to be a closed loop, circling forever, endlessly.

But program control passed right through it, and safely out the other side.

It took me two weeks to figure it out.

Address Instruction Operation
0xFFFE ADD [0xFFFE] Process data
0xFFFF ADD [0xFFFF] Last datum
0x10000 OVERFLOW! Becomes JMP!
0x0000 Next instruction Continue...

The data was near the top of memory. After the last datum, incrementing the address would overflow!

The carry would change the operation code to a JUMP instruction.

Pure genius.

The Legacy

"I have often felt that programming is an art form,

whose real value can only be appreciated

by another versed in the same arcane art;

there are lovely gems and brilliant coups

hidden from human view and admiration, sometimes forever,

by the very nature of the process."

Mel was, I think, an unsung genius.

When I left the company, the blackjack program would still cheat if you turned on the right sense switch.

And I think that's how it should be.

I didn't feel comfortable hacking up the code of a Real Programmer.

The Machines

LGP-30

  • Drum memory computer
  • Vacuum tube technology
  • 4096 words of memory
  • Hand-coded in hex

RPC-4000

  • One-plus-one addressing
  • Every instruction has GO TO
  • Drum optimization critical
  • Index register (unused by Mel)
